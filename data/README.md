# data/

Датасети сюди, але **не в git** (див. `.gitignore`). Кандидати:

- [KITTI](https://www.cvlibs.net/datasets/kitti/raw_data.php) — GNSS/INS (OXTS) + камери + лідар
- [EuRoC MAV](https://projects.asl.ethz.ch/datasets/euroc-mav/) — IMU + стерео, ground truth (для VIO)
- [TUM-VI](https://cvg.cit.tum.de/data/datasets/visual-inertial-dataset) — VIO
- [UrbanNav](https://github.com/IPNL-POLYU/UrbanNavDataset) — GNSS у міській забудові (деградація сигналу)
